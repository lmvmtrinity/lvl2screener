# Contributing

Open an issue or pull request against public `main`. Describe the change,
include focused tests, report the validation you ran, and call out security or
privacy impact.

This repository is a versioned public mirror. Maintainers reproduce accepted
work in the private canonical repository and run the complete acceptance flow
there. The contribution appears in a later public release with attribution;
merging or accepting an idea here does not deploy the application.

Never include credentials, personal data, provider datasets, local environment
files, database exports, or operational evidence in an issue or pull request.
